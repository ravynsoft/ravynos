### "AppleInternal" SDK

This SDK is an implementation of the "AppleInternal" SDK. It provides access to
internal APIs and features that are not part of the public open-source 
distributions that are needed to compile that code. We (the ravynOS developers)
have created this SDK from hints and observations and do not guarantee its
correctness. It contains 100% open source code, mostly original creations.

While this SDK is needed to build components of ravynOS, you should avoid
using it directly in your own projects. All interfaces here are subject to
change without notice. Use at your own risk.
