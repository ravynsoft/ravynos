ravynOS is an open source OS project that aims to provide a similar experience and some compatibility with macOS on x86-64 (and eventually arm64/arm64e) systems. It builds on the solid foundations of Darwin and FreeBSD, existing open source packages in the same space, and new code to fill the gaps.

Główne cele:
- Kompatybilność z aplikacjami MacOS (n.p. możesz skompilować aplikacje MacOS na ravynOS i ją odpalić). komaptybilność binarna ewentualnie.
- Podobne metafory GUI i podobnę UX (menedżer plików, launhcer aplikacji, górny pasek menu który pokazuje aktualnie otwartą aplikacje, etc) które udostępnia aplikacjom oczekiwane interfejsy API od Apple
- Kompatybilny z MacOS układ katalogów (/Library, /System, /Users, /Volumes, etc) oraz systemy plików (HFS+, APFS) dodatkowo inne przydatne systemy plików jak FAT, NTFS, ZFS.
- Samodzielne aplikacje w [App Bundles](https://developer.apple.com/documentation/foundation/bundle) z wsparciem dla plików DMG i innych archiw.
- Zaktualizowane środowisko Unix z bieżącymi narzędziami, powłokami, i zaawansowanymi narzędziami
- Wygodny w użyciu, bezpieczny, stabilny i wydajny
